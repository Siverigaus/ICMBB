# Series_2 – мутанты Cys→Ala: данные моделирования молекулярной динамики

МД-моделирование белка NaPi2b в мембране: дикий тип (WT) и мутанты с заменой остатков цистеина на аланин.
В серии 11 систем: WT, 4 одиночных и 6 двойных мутантов.
Для каждой системы рассчитаны RMSD, RMSF, SASA, Rg и PCA по внеклеточному домену и по эпитопу.

## Исследуемые системы

| Система | Тип | Замены |
|---------|-----|--------|
| `WT` | дикий тип | — |
| `C303A`, `C322A`, `C328A`, `C350A` | одиночные мутанты | одна замена Cys→Ala |
| `C303A-C322A`, `C303A-C328A`, `C303A-C350A`, `C322A-C328A`, `C322A-C350A`, `C328A-C350A` | двойные мутанты | две замены Cys→Ala |

В именах папок PCA системы обозначены номерами остатков: `303` = `C303A`, `303-322` = `C303A-C322A` и т. д.

## Условия моделирования

Протокол одинаковый для всех систем. Моделирование проведено в NAMD 3.0 (CUDA), силовое поле CHARMM36m для белка и CHARMM36 для липидов. Система собрана в CHARMM-GUI: белок в мембране, вода, ионы. Размер ячейки 120 × 112 × 172 Å, около 283 тыс. атомов.

Общие настройки: шаг 1 фс, периодические граничные условия, электростатика PME, ван-дер-ваальсовы взаимодействия обрезаются на 12 Å (сглаживание с 8 Å).

| Стадия | Длительность | Условия |
|--------|--------------|---------|
| Минимизация | 100 000 шагов | метод сопряжённых градиентов |
| Нагрев | 30 пс | 0 → 300 K, переназначение скоростей каждый шаг с шагом 0.01 K |
| Уравновешивание | 300 пс | 300 K, переназначение скоростей каждый шаг, постоянный объём |
| Моделирование | 3 × 10 нс | старт при 300 K; кадр траектории каждые 25 пс |

## Исследуемые параметры

| Параметр | Для каких частей белка | Комментарий |
|----------|------------------------|-------------|
| RMSD | ВКД, эпитоп | среднеквадратичное отклонение, Å |
| RMSF | ВКД, эпитоп | среднеквадратичная флуктуация Cα, Å |
| SASA | ВКД, эпитоп | площадь поверхности, доступная для растворителя, Å² |
| Rg | ВКД, эпитоп | радиус гирации, Å |
| PCA | ВКД, эпитоп | PC1, PC2, PC3 по координатам Cα |

Части белка: **ВКД** — внеклеточный домен (остатки 234–361), **эпитоп** — эпитоп MX35 (остатки 324–338).

## PCA

- PCA строится по координатам Cα выбранного региона. Перед расчётом каждый кадр выравнивается на исходную структуру.
- **Общий PCA**: кадры всех 11 систем объединены, выравнивание на структуру WT. Берутся только остатки, которые есть во всех системах. Все системы лежат в одном пространстве главных компонент, поэтому их можно сравнивать на одном графике.
- **PCA по системам**: считается для каждой системы отдельно, выравнивание на её собственную структуру.
- Вклад остатка в главную компоненту — среднее |au| по координатам его Cα.
- В подписях осей PC1 и PC2 указана доля объяснённой дисперсии.

Структура папки:

```
PCA_all_systems/
├── combined/        общий PCA
│   ├── VKD/
│   └── epitope/
├── per_protein/     PCA для каждой системы
│   └── <система>/
│       ├── VKD/
│       └── epitope/
└── comparison/      сравнение вкладов остатков между системами
```

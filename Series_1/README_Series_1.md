# Series_1 — данные моделирования молекулярной динамики

Результаты 100-нс MD-моделирования белка в асимметрической плазматической мембране млекопитающих (PMm).
Исследованы три системы, различающиеся набором дисульфидных связей.
Для каждой системы рассчитаны RMSD, RMSF, SASA, Rg, PCA, энергии Eel и EVdW,
а также расстояние между атомами серы остатков 303–350 и 322–328.

## Исследуемые системы

| Система | Введённые дисульфидные связи | Базовое имя запуска |
|---------|------------------------------|---------------------|
| `2_bonds` | C303–C350 и C322–C328 | `MD_2_bonds_W_I_PMm_100_ns` |
| `303_350` | только C303–C350 | `MD_303_350_W_I_PMm_100_ns` |
| `no_bonds` | связи не вводились | `MD_no_bonds_W_I_PMm_100_ns` |

Для каждого запуска присутствуют парные файлы `<базовое_имя>[_N].conf` и `<базовое_имя>[_N].out`,
где `N` — номер повторности: отсутствует для 1-й, `2` — для 2-й, `3` — для 3-й.
Подробнее — в разделе «5. Конфигурации и логи».

Имена файлов повторностей различаются суффиксом после длительности симуляции:

- первая повторность — без суффикса: `..._100_ns.txt`
- вторая повторность — суффикс `2`: `..._100_ns_2.txt`
- третья повторность — суффикс `3`: `..._100_ns_3.txt`

Примеры:

- `Rg_ECL_2_bonds_NPT_W_I_PMm_100_ns_2.txt`
- `RMSF_epitope_no_bonds_NPT_W_I_PMm_100_ns_3.txt`
- `MD_2_bonds_W_I_PMm_100_ns_2.conf` / `MD_2_bonds_W_I_PMm_100_ns_2.out`

Пример системы (скриншот из VMD): `MD_no_bonds_W_I_PMm_100_ns.png`.

## Условия моделирования (расшифровка имени)

Суффикс `NPT_W_I_PMm_100_ns` в именах файлов означает:

- **NPT** — изобарно-изотермический ансамбль на производительной 100-нс стадии.
- **W** — сольватация в водной ячейке 150 × 150 × 190 Å.
- **I** — добавлены ионы Na⁺ и Cl⁻ в концентрации 0.15 M.
- **PMm** — асимметрическая плазматическая мембрана млекопитающих.
- **100_ns** — длительность симуляции.

## Исследуемые параметры

| Параметр | Для каких частей белка | Комментарий |
|----------|------------------------|-------------|
| RMSD | protein, ECL, epitope | среднеквадратичное отклонение; для MD_ECL — с шагом 5 кадров (`stride_5`) |
| RMSF | ECL, epitope | среднеквадратичная флуктуация; для MD_ECL — с шагом 5 кадров |
| SASA | ECL, epitope | площадь поверхности, доступная для растворителя |
| Rg | ECL, epitope | радиус гирации |
| PCA | ECL | PC1, PC2, PC3; `PCA123` — все три на одном рисунке |
| Eel | protein | энергия электростатических взаимодействий |
| EVdW | protein | энергия вандерваальсовых взаимодействий |
| 303350 | остатки 303 и 350 | расстояние между атомами серы, Å |
| 322328 | остатки 322 и 328 | расстояние между атомами серы, Å |

Части белка: **protein** — весь белок, **ECL** — большой внеклеточный домен, **epitope** — эпитоп MX35.

## Соглашение об именах

Общий шаблон:

```
<префикс>_<параметр>_<система>_NPT_W_I_PMm_100_ns_[N]_[stride_5].<расширение>
```

где `N` — номер повторности: отсутствует для 1-й, `2` — для 2-й, `3` — для 3-й.

### Префиксы (тип обработки)

| Префикс | Значение |
|---------|----------|
| (без префикса) | сырые данные |
| `edit` | отредактированные данные: убрана лишняя строка, введены заголовки |
| `paint` / `paint2`, `paint3` … | график отредактирован в Paint (номер — номер редакции) |
| `statistics` | статистика по параметру |
| `summary` | краткое изложение числовых результатов по параметру |
| `multiplot` | данные для мультиплотов |
| `boxplots` / `paint_boxplots` | ящики с усами (сырые / отредактированные) |
| `hist` / `hists` / `paint_hists` | гистограмма (одна / несколько на рисунке / отредактированные) |
| `plot` / `plots` / `paint_plots` | графики (один / несколько на рисунке / отредактированные) |

### Параметры

- `RMSD`, `RMSF`, `SASA`, `Rg` — стандартные метрики МД.
- `PCA`, `PC1`, `PC2`, `PC3`, `PCA123` — анализ главных компонент.
- `Eel`, `EVdW` — энергии.
- `303350`, `322328` — расстояния S–S между остатками.
- `stride_5` — анализ каждого 5-го кадра траектории.

### 1. Сырые данные (.txt)

Временные ряды и значения параметров без префикса.
Примеры:

- `Rg_ECL_2_bonds_NPT_W_I_PMm_100_ns.txt`
- `RMSF_epitope_no_bonds_NPT_W_I_PMm_100_ns.txt`
- `SASA_ECL_303_350_NPT_W_I_PMm_100_ns.txt`
- `Eel_protein_2_bonds_NPT_W_I_PMm_100_ns.txt`
- `EVdW_protein_no_bonds_NPT_W_I_PMm_100_ns.txt`
- `303350_2_bonds_NPT_W_I_PMm_100_ns.txt`
- `322328_2_bonds_NPT_W_I_PMm_100_ns.txt`
- `multiplot_RMSD_ECL_2_bonds_NPT_W_I_PMm_100_ns.txt` — агрегированные данные для мультиплота
- `summary_RMSD_MD_ECL_NPT_W_I_PMm_100_ns_stride_5.txt` — сводка числовых результатов по RMSD
- `summary_RMSF_MD_ECL_NPT_W_I_PMm_100_ns_stride_5.txt` — сводка числовых результатов по RMSF

### 2. Отредактированные данные (.txt, префикс `edit`)

Сырые данные после правки: убрана лишняя строка, добавлены заголовки.
Примеры:

- `edit_Rg_ECL_NPT_W_I_PMm_100_ns.txt`
- `edit_RMSF_ECL_NPT_W_I_PMm_100_ns.txt`
- `edit_multiplot_RMSD_protein_NPT_W_I_PMm_100_ns.txt`
- `edit_303350_NPT_W_I_PMm_100_ns.txt`

### 3. Статистика (.txt, префикс `statistics`)

Результаты статистической обработки по параметрам (RStudio).
Примеры:

- `statistics_RMSD_ECL_NPT_W_I_PMm_100_ns.txt`
- `statistics_SASA_epitope_NPT_W_I_PMm_100_ns.txt`
- `statistics_PCA_MD_ECL_NPT_W_I_PMm_100_ns_stride_5.txt`

### 4. Графики (.png)

| Префикс | Тип графика |
|---------|-------------|
| `boxplots` | ящики с усами, сырые |
| `paint_boxplots` | ящики с усами, отредактированные |
| `hist` / `hists` | гистограмма (одна / несколько) |
| `paint_hists` | то же, отредактированные |
| `plots` | графики зависимостей (несколько на рисунке), сырые |
| `paint_plots` | то же, отредактированные |
| `plot` | отдельный график |
| `plot_PCA123` | все три главные компоненты на одном рисунке |

Примеры:

- `boxplots_RMSD_ECL_NPT_W_I_PMm_100_ns.png`
- `paint_boxplots_SASA_epitope_NPT_W_I_PMm_100_ns.png`
- `plots_Rg_ECL_NPT_W_I_PMm_100_ns.png`

- `plot_PCA123_MD_ECL_no_bonds_NPT_W_I_PMm_100_ns_stride_5.png`
- `hist_RMSD_MD_ECL_no_bonds_NPT_W_I_PMm_100_ns_stride_5.png`

### 5. Конфигурации и логи (.conf, .out)

Для каждой системы — по одному `.conf` (входной конфиг) и одному `.out` (лог) на каждый запуск.
Номер повторности указывается суффиксом в конце имени, как и у остальных файлов:

```
MD_<система>_W_I_PMm_100_ns[_N].conf
MD_<система>_W_I_PMm_100_ns[_N].out
```

где `<система>` — `2_bonds`, `303_350` или `no_bonds`,
`N` — номер повторности: отсутствует для 1-й, `2` — для 2-й, `3` — для 3-й.

Примеры:

- `MD_2_bonds_W_I_PMm_100_ns.conf` / `MD_2_bonds_W_I_PMm_100_ns.out`
- `MD_2_bonds_W_I_PMm_100_ns_2.conf` / `MD_2_bonds_W_I_PMm_100_ns_2.out`
- `MD_2_bonds_W_I_PMm_100_ns_3.conf` / `MD_2_bonds_W_I_PMm_100_ns_3.out`

### 6. Итоговые документы

- `Systems_comparison.xlsx` — сравнительная таблица по системам.

### 7. Служебные

- `files.md` — автоматически сгенерированный список всех файлов.

## Примечания

- Файлы с `stride_5` используют каждый 5-й кадр траектории.
- Префикс `paint` обозначает график, отредактированный в Paint; номер (`paint2`, `paint3`) — номер редакции.
- `MD_no_bonds_W_I_PMm_100_ns.png` — скриншот из VMD с примером исследуемой системы.
- Имена файлов без префикса — это исходные (сырые) данные.

# Анализ сетей взаимодействий аминокислотных остатков

Пакетный анализ траекторий NAMD (PSF/DCD): построение белковых сетей взаимодействий остатков (RIN), расчёт центральностей, выделение хабов и контроль качества.

Каждая траектория анализируется отдельно. Липиды, гликаны и другие небелковые компоненты не включаются в сети.

## Файлы

- `NAMD_Protein_RIN_Centrality_Batch_Analysis.ipynb` — основной ноутбук.
- `systems_batch2.csv` — таблица входных систем.
- `summary_all_systems.csv` — метрики центральности и признаки хабов для остатков.
- `summary_all_hubs.csv` — хабы по пересечению критериев degree и betweenness.
- `summary_all_edges.csv` — взаимодействия между остатками.
- `summary_system_qc.csv` — параметры анализа, характеристики графов и статусы обработки.

## Запуск

1. Подготовьте таблицу систем с колонками `system_id`, `batch`, `length_ns`, `psf_path`, `dcd_path`.
2. Укажите путь к таблице в `SYSTEMS_CSV` и выберите группы в `RUN_BATCHES`.
3. Проверьте параметры анализа и последовательно выполните ячейки ноутбука.

Зависимости: Python, MDAnalysis, NetworkX, pandas, NumPy и tqdm. Отсутствующие основные библиотеки устанавливаются первой ячейкой.

## Результаты и ограничения

Результаты сохраняются в `rin_centrality_results/`: отдельные таблицы для каждой системы и общие CSV-файлы.

Перед интерпретацией проверьте диагностику периодических границ: ноутбук не исправляет разрывы белка автоматически. Сети разных траекторий не объединяются в один граф.
